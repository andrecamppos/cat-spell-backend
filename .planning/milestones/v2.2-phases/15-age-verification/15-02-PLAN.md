<objective>
Relocate the date of birth from `user_profiles` to `users` as the single source of truth, collect it at register, hard-block under-18 signups behind the `AgeVerifier` seam before any account row is created, and repoint every DOB reader — all in one atomic change so the schema, entities, readers, and tests stay consistent.

Purpose: The V22 migration drops `user_profiles.date_of_birth` (D-10); every reader of that column (register/User, discovery SQL + service, profile DTOs/service) and every test that seeds DOB via the profile must change together, or the build/suite cannot be green. Splitting these across waves would guarantee a red intermediate (dropped column + stale readers/tests), so this plan is deliberately one coherent unit executed after the 15-01 seam.
Output: V22 migration; `RegisterRequest.dateOfBirth` + register gate; nullable `User.dateOfBirth`; DOB removed from the profile layer + `ProfileService.validateAge` deleted; discovery filter/service sourced from `users`; new `AgeGateIntegrationTest` + `DobMigrationTest`; existing DOB-dependent test fixtures updated.
</objective>
