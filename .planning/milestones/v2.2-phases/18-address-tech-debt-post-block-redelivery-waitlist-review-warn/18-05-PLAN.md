<objective>
Close the minimum-length half of first-review WR-08 (D-13): the guard enforces no minimum token length, so a weak `INVITE_ADMIN_TOKEN`, which unlocks every waitlist email and invite minting, can be brute-forced. After this plan, a non-blank token shorter than 32 characters stops the application at startup. The per-IP admin throttle half of D-13 is 18-07; the central guard (D-11) and the stale-Bearer fix (D-12) are 18-10.

The startup rule breaks every test context that uses the 17-character test secret (RESEARCH Pitfall 2). This plan moves all four classes onto one shared 34-character constant in the same plan.

Reversibility: D-13 is rated **costly** in CONTEXT.md (flagged, not gated). Any deploy with a short `INVITE_ADMIN_TOKEN` won't start until the token is rotated. 18-11 documents this in docs/CONFIGURATION.md.

Spec-less probe fallback skipped: the phase has no requirement IDs to probe (visible skip).

Git: **stage only, never commit**. Stage this plan's paths explicitly with `git add <path>`.
</objective>
