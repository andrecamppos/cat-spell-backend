| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-16-01 | Tampering | invites.code_hash | high | mitigate | Store SHA-256 hex only (`code_hash VARCHAR(64) NOT NULL`); raw code never has a column — a table leak yields no usable codes (INV-04, D-06). |
| T-16-02 | Tampering/Elevation | invites.consumed_at | high | mitigate | `consumed_at` is the single-use claim target; `InviteRepository.markConsumed` uses a conditional UPDATE `WHERE consumed_at IS NULL` (atomic claim, closes the double-consume race — INV-04, D-07). |
