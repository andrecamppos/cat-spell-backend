# Plan 05-02: Conversation List + Unread Counts + Offline Delivery

<objective>
**As a** matched user, **I want to** see a list of my conversations with unread counts and last message preview, mark conversations as read, and receive missed messages when I reconnect, **so that** I never miss a message and can quickly find active chats.

Completes the chat experience by adding: conversation listing with rich metadata (other user + cats + unread count + last message), mark-read endpoint, and offline message delivery on WebSocket reconnect.
</objective>

<must_haves>
## Goal-Backward Verification

### Truths (from CONTEXT.md decisions)
- D-04: Conversation list returns: other user's display name + first photo, last message preview (truncated text + timestamp), unread count, plus their cats (names + first photo each)
- D-05: Queue + deliver on reconnect — server pushes undelivered messages via WebSocket when user reconnects
- D-06: Messages table has `delivered` boolean. On reconnect, query undelivered and push. Mark delivered after push
- D-07: WebSocket pushes lightweight notification for new messages across ALL conversations
- D-08: REST conversation list includes server-computed unread count (from last_read_at vs message timestamps)

### Must-Haves
1. GET `/api/conversations` returns list of conversations with other user info, cat info, last message preview, and unread count
2. POST `/api/conversations/{id}/read` updates `last_read_at` for the calling user
3. On WebSocket reconnect, undelivered messages are pushed to the user and marked as delivered
4. Unread count is computed server-side from `last_read_at` vs message `created_at`
5. Conversation list is sorted by `last_message_at` descending
</must_haves>

## Task 2: Implement conversation list + mark read in ChatService

<read_first>
- src/main/kotlin/com/catspell/api/chat/service/ChatService.kt
- src/main/kotlin/com/catspell/api/match/service/MatchService.kt
- src/main/kotlin/com/catspell/api/chat/model/ConversationParticipantRepository.kt
- src/main/kotlin/com/catspell/api/profile/model/UserProfileRepository.kt
- src/main/kotlin/com/catspell/api/cat/model/CatProfileRepository.kt
- src/main/kotlin/com/catspell/api/cat/model/CatPhotoRepository.kt
</read_first>

<action>
Add to `ChatService`:

**getConversations(userId: UUID): ConversationListResponse**
1. Query all conversations where user is a participant (via `conversationParticipantRepository.findByUserId(userId)`)
2. For each conversation's participant entry:
   a. Get the conversation entity
   b. Determine `otherUserId` from match (similar to MatchService.getMatches pattern)
   c. Look up other user's profile: display name + first active photo thumbnail (reuse UserProfileRepository, UserPhotoRepository pattern from MatchService)
   d. Look up other user's cats: names + first active photo thumbnail (reuse CatProfileRepository, CatPhotoRepository pattern from MatchService)
   e. Get last message via `messageRepository.findTopByConversationIdOrderByCreatedAtDesc`
   f. Compute unread count: if `participant.lastReadAt` is null, count all messages not sent by user; otherwise count messages after `lastReadAt` not sent by user
   g. Build `ConversationResponse` with `MatchUserSummary`, `List<MatchCatSummary>`, `LastMessagePreview`, `unreadCount`
3. Sort by `lastMessageAt` descending (nulls last)
4. Return `ConversationListResponse`

**markRead(userId: UUID, conversationId: UUID)**
1. Find participant entry via `conversationParticipantRepository.findByConversationIdAndUserId`
2. If not found, throw ResourceNotFoundException
3. Set `participant.lastReadAt = Instant.now()`
4. Save participant
</action>

<acceptance_criteria>
- `getConversations` returns list with otherUser, otherUserCats, lastMessage, unreadCount
- `getConversations` sorts by lastMessageAt descending
- `markRead` updates lastReadAt for the calling user's participant row
- `markRead` throws ResourceNotFoundException for non-participant
- Unread count is 0 after markRead is called
- `./gradlew compileKotlin` exits 0
</acceptance_criteria>

## Task 4: Implement offline message delivery on reconnect

<read_first>
- src/main/kotlin/com/catspell/api/common/security/WebSocketAuthInterceptor.kt
- src/main/kotlin/com/catspell/api/chat/service/ChatService.kt
- src/main/kotlin/com/catspell/api/chat/model/MessageRepository.kt
- src/main/kotlin/com/catspell/api/chat/model/ConversationParticipantRepository.kt
</read_first>

<action>
Add to `ChatService`:

**deliverUnreadMessages(userId: UUID)**
1. Get all conversation IDs where user is a participant
2. Query `messageRepository.findByConversationIdInAndDeliveredFalseAndSenderIdNotOrderByCreatedAtAsc(conversationIds, userId)`
3. For each undelivered message:
   a. Look up sender display name
   b. Send via `SimpMessagingTemplate.convertAndSendToUser(userId.toString(), "/queue/notifications", ChatNotification(...))`
   c. Mark `message.delivered = true`, save
4. Return count of delivered messages

**Trigger on reconnect:**
Modify `WebSocketAuthInterceptor` — after successful CONNECT authentication, call `chatService.deliverUnreadMessages(userId)`. Use `@Async` or schedule with slight delay (100ms) to ensure STOMP session is fully established before pushing messages.

Alternative approach (simpler): Add a `@EventListener` for `SessionConnectedEvent` in ChatService or a separate component. When a user's session connects, trigger delivery. This is cleaner than doing it in the interceptor.
</action>

<acceptance_criteria>
- `deliverUnreadMessages` queries undelivered messages across user's conversations
- Each undelivered message is pushed via `/user/{userId}/queue/notifications`
- Messages are marked `delivered = true` after push
- Delivery triggered on WebSocket session connect (via SessionConnectedEvent or interceptor)
- `./gradlew compileKotlin` exits 0
