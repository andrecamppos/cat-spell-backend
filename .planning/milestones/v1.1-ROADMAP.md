# Milestone v1.1: Mixed Discovery

**Status:** ✅ SHIPPED 2026-06-23
**Phases:** 7
**Total Plans:** 2

## Overview

Make cat ownership optional and transform discovery into a mixed feed of cats and humans. Users with cats show cat cards (cat-first preserved), users without cats show human cards. The app is open to all cat lovers, not just cat owners.

## Phases

### Phase 7: Mixed Discovery Feed

**Goal:** Transform discovery from cat-only to a mixed feed — users with cats show cat cards (cat-first preserved), users without cats show human cards.
**Depends on:** Phase 4, Phase 6
**Plans:** 2 plans
**Requirements:** DISC-08, DISC-09, DISC-10, DISC-11, DISC-12

Plans:

- [x] 07-01: Schema & Model Foundation — V13 migration (nullable cat_id), Swipe entity update, FeedProjection rewrite, polymorphic DTOs, test updates
- [x] 07-02: Mixed Feed Query, Swipe Logic & Integration Tests — UNION ALL query, human card detail endpoint, 15 new integration tests

**Success Criteria:**

1. Users without cats appear in the discovery feed as human cards (user profile info + photos)
2. Users with cats still appear as cat cards (cat-first reveal preserved)
3. Feed items include a `type` discriminator (`CAT` or `HUMAN`) so clients render the right card
4. Swipe endpoint accepts either `catId` (cat card) or `targetUserId` (human card), not both
5. Mutual match detection works for both cat-based and direct user-based swipes
6. Previously seen profiles (via either path) are excluded from future feeds
7. Owner profile endpoint still works for cat cards; human cards link directly to user profile

## Milestone Summary

**Key Decisions:**

- Optional cat ownership — widens user base to all cat lovers, not just owners
- Mixed discovery feed — UNION ALL query produces polymorphic feed items (CAT + HUMAN)
- Partial unique indexes — replaced single unique constraint with two partial indexes for cat/human swipe deduplication
- ROW_NUMBER per owner — one cat card per multi-cat user (first-created cat)
- Exactly-one validation — SwipeRequest enforces `catId XOR targetUserId`

**Issues Resolved:**

- Test contamination from shared locations — unique coordinates per test scenario
- Feed exclusion unified on `target_user_id` for both card types

- None

- None identified
