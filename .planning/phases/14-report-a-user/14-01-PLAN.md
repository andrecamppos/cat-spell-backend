<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client (JSON body) → ReportRequest DTO | Untrusted free-text details + category + reportedUserId + alsoBlock cross here (validated declaratively before the service). |
| application code → PostgreSQL (reports) | DB-level CHECK constraints backstop the service-layer invariants (self-report, category domain). |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-14-01 | Tampering | `details` free-text field | medium | mitigate | `@field:NotBlank` + `@field:Size(max=1000)` on the DTO → RFC 7807 400; DB `details VARCHAR(1000)` backstop. |
| T-14-02 | Tampering | `category` field | medium | mitigate | Enum-typed category → unknown/lowercase/null fails Jackson → 400; DB `chk_reports_category` CHECK backstop. |
| T-14-03 | Elevation/Abuse | self-report (reporter==reported) | high | mitigate | `SelfReportException` → 400 (service layer, 14-02) + `chk_reports_no_self` CHECK defence-in-depth in V21. |
| T-14-04 | Information Disclosure | reporter identity toward reported user (retaliation, D-11) | high | mitigate | `ReportResponse` exposes only `reportId`; no DTO/event field carries reporter identity toward the target; event is operator-bound only. |
| T-14-05 | Repudiation / evidence loss | duplicate-report dedupe | medium | mitigate | No UNIQUE(reporter_id, reported_id) — every report persists (D-04), preserving the full evidence trail. |
| T-14-06 | Tampering | migration history | high | mitigate | Append-only V21; V1–V20 never edited (Flyway checksum integrity). |
| T-14-01-SC | Tampering | npm/pip/cargo installs | n/a | accept | No package installs in this phase (no build.gradle.kts change); supply-chain checkpoint not applicable. |
</threat_model>
