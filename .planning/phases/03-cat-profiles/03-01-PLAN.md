<objective>
Deliver the cat profile CRUD system — Flyway migration, JPA entity with age+ageUnit model, repository, service with 5-cat limit, controller at `/api/cats`, and integration tests. This is a complete vertical slice: DB → entity → service → controller → tests.
</objective>

<must_haves>
- Cat profiles table with FK to users and ON DELETE CASCADE
- AgeUnit enum (YEARS/MONTHS) stored as VARCHAR
- CRUD endpoints: create, list, get, update, delete at /api/cats
- 5-cat-per-user limit enforced at service level
- Ownership validation: users can only manage their own cats
- Integration tests for all CRUD operations and edge cases
</must_haves>
