<objective>
Deliver cat photo management mirroring the established user photo upload flow (presigned URL → upload → confirm → thumbnail), with cat-specific S3 paths (`cats/{catId}/`), 10-photo-per-cat limit, and full cascade deletion (user → cats → cat photos + S3 objects).
</objective>

<must_haves>
- Cat photos table with FK to cat_profiles and ON DELETE CASCADE
- CatPhotoService mirroring PhotoService: presigned URL, confirm, thumbnail, delete, reorder, list
- S3 key pattern: cats/{catId}/{uuid}.{ext} and thumbnails/cats/{catId}/{photoId}.jpg
- 10-photo-per-cat limit
- Ownership chain: photoId → catId → userId validation
- Cat profile deletion cascades to S3 object cleanup
- Integration tests for photo upload flow and cascade deletion
</must_haves>

### Task 6: CatPhotoService

<read_first>
- src/main/kotlin/com/catspell/api/profile/service/PhotoService.kt
- src/main/kotlin/com/catspell/api/profile/service/StorageService.kt
- src/main/kotlin/com/catspell/api/cat/model/CatPhoto.kt

<action>
Create `src/main/kotlin/com/catspell/api/cat/service/CatPhotoService.kt` mirroring PhotoService with these changes:

Constants: `MAX_PHOTOS = 10`, `MAX_FILE_SIZE_BYTES = 10_485_760L`, `ALLOWED_CONTENT_TYPES = setOf("image/jpeg", "image/png")`

`requestUploadUrl(userId: UUID, catId: UUID, request: CatUploadUrlRequest): CatUploadUrlResponse` — verify cat ownership (catProfile.user.id == userId), check photo count < 10, create PENDING CatPhoto record, generate presigned URL with S3 key `cats/{catId}/{uuid}.{ext}`. `@Transactional`

`confirmUpload(userId: UUID, catId: UUID, photoId: UUID): CatConfirmUploadResponse` — verify ownership chain, check PENDING status, verify S3 object exists, download original, generate 200×200 thumbnail, upload to `thumbnails/cats/{catId}/{photoId}.jpg`, set status ACTIVE. `@Transactional`

`deletePhoto(userId: UUID, catId: UUID, photoId: UUID)` — verify ownership, delete S3 original + thumbnail, delete DB record, re-index display orders. `@Transactional`

`reorderPhotos(userId: UUID, catId: UUID, request: CatReorderRequest)` — verify ownership, validate photo IDs match all active photos, update display orders. `@Transactional`

`listPhotos(userId: UUID, catId: UUID): List<CatPhotoResponse>` — verify ownership, return ACTIVE photos ordered by displayOrder

Private helper: `verifyCatOwnership(userId: UUID, catId: UUID): CatProfile` — find cat by id and userId, throw ResourceNotFoundException if not found. Used by all methods.

Private helper: `generateThumbnail(data: ByteArray): ByteArray` — use Thumbnailator to resize to 200×200 JPEG (same as PhotoService)

Private helper: `toResponse(catPhoto: CatPhoto): CatPhotoResponse`
</action>

<acceptance_criteria>
- `requestUploadUrl` generates S3 key as `cats/{catId}/{uuid}.{ext}`
- `confirmUpload` generates thumbnail at `thumbnails/cats/{catId}/{photoId}.jpg`
- All public methods verify cat ownership via `verifyCatOwnership(userId, catId)`
- `deletePhoto` deletes both S3 original and thumbnail objects
- `reorderPhotos` validates that provided photoIds exactly match all ACTIVE photos for the cat
- Photo count limit is 10 (checked against PENDING + ACTIVE statuses)
</acceptance_criteria>
