<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client → API | Untrusted HTTP requests from mobile app cross into backend |
| API → Database | Authenticated service queries cross into data layer |
| JWT Token | Bearer token travels over network, stored on client device |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Spoofing | /api/auth/login | mitigate | BCrypt password hashing; vague error messages prevent user enumeration (D-15) |
| T-01-02 | Tampering | JWT tokens | mitigate | HMAC-SHA512 signing with 512-bit secret; signature validation on every request via JwtAuthenticationFilter |
| T-01-03 | Repudiation | Auth operations | accept | No audit logging for v1; accept risk at current scale |
| T-01-04 | Information Disclosure | Error responses | mitigate | Safe production defaults (D-15): generic 500s, vague auth errors, field-level validation only |
| T-01-05 | Denial of Service | /api/auth/register, /api/auth/login | accept | No rate limiting in Phase 1; deferred to Phase 6 hardening |
| T-01-06 | Elevation of Privilege | JWT claims | mitigate | JWT contains only userId and email; no role escalation possible; token validated on every request |
| T-01-07 | Information Disclosure | JWT secret | mitigate | Secret loaded from environment variable JWT_SECRET; never committed to source; .env in .gitignore |
| T-01-SC | Tampering | Gradle dependency installs | mitigate | All dependencies are well-known Spring Boot ecosystem packages from Maven Central; versions pinned in build.gradle.kts |
</threat_model>
