<objective>
Expose the operator issuance surface: a `POST /api/admin/invites` endpoint whitelisted `permitAll` in `SecurityConfig` and guarded by a constant-time `X-Admin-Token` shared-secret check with deny-by-default when unconfigured. It calls `InviteService.create` and returns the raw code exactly once.

Purpose: This is the only way the operator bootstraps the first users (INV-02). Because the app has no admin role/JWT user (D-03), the header check is the entire access-control boundary — so it must be constant-time and closed-by-default.
Output: `InviteAdminController`, the `SecurityConfig` whitelist entry, and an admin-endpoint integration test.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator/client → POST /api/admin/invites | A permitAll route: the X-Admin-Token header check is the ONLY access-control barrier (no JWT/role). |
| InviteAdminController → InviteService | Issuance delegates to the service; the referrer id is validated there. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-16-11 | Elevation of Privilege | permitAll admin route unconfigured | high | mitigate | Deny-by-default: `requireValidAdminToken` rejects when `app.invite.admin-token` is blank; no guessable default ships (Pitfall 4, D-03). |
| T-16-12 | Information Disclosure | X-Admin-Token comparison | high | mitigate | Constant-time `MessageDigest.isEqual` compare; never `==`/`String.equals` (timing side channel). |
| T-16-13 | Spoofing | bad/missing admin token response | medium | mitigate | Generic 401 (title 'Unauthorized', no code hint) so a caller cannot distinguish missing vs wrong token (D-03). |
| T-16-14 | Tampering | referrerUserId at issuance | medium | mitigate | `InviteService.create` rejects an unknown non-null referrer with 400; prevents dangling attribution (D-12). |
| T-16-15 | Denial of Service | unbounded issuance by a leaked token | low | accept | Single-use + operator-controlled volume bounds abuse; rate-limiting/revocation are deferred (D-05) — accepted at ASVS L1 for an operator-only surface. |
| T-16-SC | Tampering | dependency installs | low | accept | No new dependencies this phase (RESEARCH audit: none). |
