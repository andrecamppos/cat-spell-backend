<threat_model>
## Threat Model

### T1: Owner Profile Over-Exposure
- **Severity:** MEDIUM
- **Attack:** Owner profile endpoint exposes sensitive data (raw coordinates, email, etc.)
- **Mitigation:** OwnerProfileResponse only includes displayName, bio, age (calculated), gender, photos, cats. No email, no coordinates, no raw DOB.

### T2: Match List Data Leakage
- **Severity:** LOW
- **Attack:** User retrieves another user's match list via parameter manipulation
- **Mitigation:** Match list endpoint uses extractUserId() from JWT — always returns only the authenticated user's matches. No user ID parameter accepted.

### T3: Unrestricted Owner Profile Access
- **Severity:** LOW
- **Attack:** Any authenticated user can view any cat's owner profile (not restricted to discovery context)
- **Mitigation:** Acceptable for v1 — the owner profile only contains public-facing data. In v2, could restrict to users who have seen the cat in their feed.
</threat_model>
