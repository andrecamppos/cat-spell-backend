<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → forgot flow | Untrusted email input; response must not reveal whether the account exists. |
| client → reset flow | Untrusted raw token + new password; only a valid, unused, unexpired token may mutate state. |
| filter tier → controller | Public routes must bypass JWT auth yet remain rate-limited. |

| T-10-09 | Spoofing/Tampering | Reset-token brute force | high | mitigate | 256-bit SecureRandom token + 30-min TTL (Task 1) + per-IP + per-email rate limiting (Task 1/3). |
